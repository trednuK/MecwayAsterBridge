# Verification of the MecwayAsterBridge

*Nederlandse versie: [Verificatie.md](../Verificatie.md)*

This report shows with reproducible tests that the chain Mecway model (`.liml`) →
MecwayAsterBridge → Code-Aster 17.4 → results in Mecway gives correct answers. Each
test compares a FEM quantity with an analytical solution or a recognised benchmark, in
the style of the NAFEMS benchmarks (NAFEMS, 1990): small, focused and with a tolerance
justified beforehand. In addition, the Code-Aster installation itself was tested with
19 official validation tests (§10).

(NL) · 6 Dynamics (DY) · 7 Modal (MO) and buckling (BU) · 8 Thermal (TH) ·
9 Assumptions and not covered · 10 Official Code-Aster validation tests · 11 References

## 1. Method

- **Models** are generated by Python scripts (`TestFiles/Verificatie/tests_*.py`, with
  `verif_lib.py`) and stored as ordinary Mecway models in
  `TestFiles/Verificatie/modellen/` (they can be opened in Mecway).
- **Solving**: `TestFiles/Verificatie/_run_one.py` takes each model through the same
  steps as a run from Mecway (`bridge_from_liml` → `bridge_mesh` →
  `bridge_to_aster`/`bridge_thermal` → Code-Aster), without the Mecway API. The results
  come from the same results file that Mecway loads.
- **Models written by Mecway**: the generator writes the `.liml` itself, not Mecway.
  With `--mecway-opslaan` (§2) Mecway first opens each model and saves it again
  (its own XML layout and order, units on every value, defaults such as `colorrgb`, an
  empty `<solution>`), so the bridge reads the file as a user saves it in Mecway.
  Outcome (7 October 2026, bridge 8742df0): all 270 test cases could go through
  Mecway, and all 1611 checks are identical to the normal run (same status, same FEM
  value); the `.comm` is the same, apart from the last digits in 15 cases (Mecway
  writes numbers with 15 significant digits).
- **Settings**: the defaults of `CONFIG_BRIDGE` (`Scripts/bridge_utils.py`), unless
  stated otherwise for a test.
- **Comparison**: per check the FEM value, the reference, the deviation and the
  tolerance. Status OK, NOK, FOUT (no result, or the requested time was not reached) or
  BEKEND (known: a deviation caused by a documented limitation, with its number in
  `KNOWN_BUGS.md`).
- **Mesh convergence**: series with decreasing element size h. Per series the error per
  mesh, the order p from successive errors and a Richardson extrapolation from the last
  three meshes (order and limit, independent of the reference). A limit that differs
  from the reference points to a model error of the theory (e.g. the clamped solid beam
  against beam theory), not to discretisation.
- **Tolerance policy**: the finest mesh gets tol_f = model error of the analytical
  theory + rounding of the reference + generously the estimated discretisation error. A
  coarser mesh with element size h gets tol_f·(h/h_f)^p (p = expected order, capped at
  50%); a coarse mesh thus only tests whether the error fits convergence towards the
  reference. Where the FEM solution is exact (e.g. Euler beam with a tip load,
  homogeneous stress) the tolerance is 0.1% or less. Tolerances were not widened
  afterwards; any deviation from this rule is justified with the test.
- **Reference values** come from the literature (§11) or from an accurate calculation of
  our own (series expansion, Runge-Kutta, the same discrete scheme in 1D), which is in
  the test module.

## 2. Running

```bash
cd TestFiles/Verificatie
python run_verificatie.py            # everything (about an hour)
python run_verificatie.py LS NL-02   # only ids starting like this
python run_verificatie.py --report   # only regenerate the report
```

Requires CPython 3 and a working Code-Aster installation (`exe_aster` in
`Scripts/bridge_utils.py`). Output: `TestFiles/Verificatie/resultaten/resultaten.md`
(all checks and the mesh convergence), `resultaten.csv`, `resultaten.json` and the
generated `.comm` per test in `resultaten/comm/` (absolute paths in it replaced by
`<WORKDIR>` and `<REPO>`, so the repository holds no machine-specific paths). Working files are in
`%TEMP%/mab_verificatie` (can be set with the environment variable `VERIF_WORK`). Heavy cases outside the standard regression (WE-10b, ~1 hour) only run with `VERIF_ZWAAR=1`.

**Through Mecway** (`python run_verificatie.py --mecway-opslaan [ids]`, or
`VERIF_MECWAY=1`): each generated model first goes through Mecway,
`mecway.exe <model>.liml script TestFiles/Tools/mw_save_as.py` (Mecway manual §16.1:
open the model, run the script, exit; no window and no solve, so it also works for
analyses Mecway cannot solve itself, such as XFEM, welding and fatigue). The script
only calls `mw.save_as()`. The bridge then solves that Mecway copy (in
`VERIF_WORK/_mecway/`); `run_verificatie` first checks that Mecway did not change node
numbers, coordinates or node selections. Output in `resultaten/mecway/` (the normal
results are left unchanged) and `resultaten/mecway/vergelijking.md` (only that file is in the repo): per check the
status and FEM value next to the normal run, and whether the `.comm` (without comments
and paths) is the same. `--mecway-opslaan --vergelijk` only regenerates that
comparison. It costs about 2 s of Mecway per model on top of the normal run. What
Mecway changes when saving: units on values without a unit (`816.0` →
`816 Pa.s/m`), numbers written differently (`1e+08 Pa` → `100000000 Pa`, 15
significant digits), selections in a different order, defaults added (`colorrgb`,
`selfcontact`, an empty `<mechanical type="Isotropic" />` on a thermal-only material,
a `<hardeningcurve strain="0" stress="0 Pa" />` with bilinear plasticity) and some
attributes dropped (`automatictimestepping="false"`, the constant values next to a
TempDependent table). Node and element numbers stay the same. After its first loop
AD-02 already runs on models that Mecway itself refined and saved; WE-10b (only with
`VERIF_ZWAAR=1`) was not part of the comparison.

Adding a test: a `Case` in a `tests_<group>.py` with a function that builds a `Model`
and a list of `Check`s (see `verif_lib.py` and the existing modules).

**Known limitations** (status BEKEND):

**Bridge errors found by this verification and fixed**:
- Error estimator: Code-Aster's `ERME` computes `FORCE_FACE` with the reversed sign (block under
  uniform tension: 15% instead of 0); the bridge reverses it in the load of the estimator (AD,
  [Error_estimator.md](Error_estimator.md) §2.3; FS unchanged, ≤ 3e-4).
- Mecway's *tangent modulus* for bilinear plasticity was read as a slope in total
  strain; it is the plastic modulus H. Now `D_SIGM_EPSI` = E·H/(E+H) (NL-01).
- Contact on quadratic faces did not pass the patch test with the default integration
  (up to 4.6% error); now `INTEGRATION='NCOTES'` for a quadratic slave face (NL-03c–f).
- Springs and dampers only acted in global X; now along their own axis (LS-06).
- *Node temperature* (`temperature3`) was ignored in a mechanical analysis (only an
  INFO); now a temperature per node in the nodal field (LS-08).
- Bonded contact between shells stopped with `FACTOR_11` (the rotation about the
  plate normal was tied as well); now without that rotation (LS-07, KNOWN_BUGS 91).
- In explicit dynamics, rounding in `DEFI_LIST_INST` gave an extra solver step.
- Temperature-dependent ρc: `THER_NON_LINE` interpolates the enthalpy linearly between
  the table points; the bridge now refines the table (energy balance from −2.8% to
  0.002%, WE-04b).
- Two weld sources (`#ASTER-LASBRON`) acted as twice the first one: Code-Aster 17.4
  computes two `AFFE_CHAR_THER_F` loads with `SOURCE` in one analysis with the function
  of the first (KNOWN_BUGS 70); the weld sources are now in one load (WE-11).
- Filler material: with the consistent heat capacity a not-yet-born node heated up
  through the mass coupling (+138 K); now `3D_DIAG` (WE-13).

## 4. Linear static (LS)

Mecway S30 → bridge `lin_static_3d` → `MECA_STATIQUE`. Module
`tests_lineair_statisch.py`, run with `python run_verificatie.py LS`. Material
everywhere steel, E = 210 GPa, ν = 0.3 (G = 80.77 GPa); SI units. The column "orde p"
in `resultaten.md` is computed from the error relative to the reference; when the
reference has a model error (LS-02), the order from the differences between successive
meshes is given below.

### LS-01 Cantilever, beam elements

- **Purpose**: beam elements (`POU_D_E`), `fixed` and a point load.
- **Model**: L = 1 m, round Ø 20 mm, 10 line2.
- **Boundary conditions and load**: clamped at x = 0, tip load P = 100 N transverse.
- **Reference**: δ = PL³/3EI, θ = PL²/2EI (Young & Budynas, 2002, table 8.1, case 1a).
- **Result**: δ, θ and the reaction deviate 0.00% (tolerance 0.1%).
- **Interpretation**: Euler-Bernoulli elements are exact for this load; the translation
  of cross-section, material and load is correct.

### LS-02 Cantilever, solid elements

- **Purpose**: solid elements (hex8 `3D`, hex8 `LINE_QUAD`, hex20), `traction`, nodal
  stresses (`SIGM_NOEU`) and reactions.
- **Model**: 1 × 0.1 × 0.1 m (axis x), cross-section n × n and length 10n cubes. Series
  hex8 `3D` (default; n = 1, 2, 4, 8, 16), hex8 `LINE_QUAD` (n = 1, 2, 4) and hex20
  (n = 1, 2, 4).
- **Boundary conditions and load**: `fixed` at x = 0; `traction` −1 MPa in z on the end
  face (P = 10 kN).
- **Reference**: Timoshenko beam δ = PL³/3EI + PL/(κGA), κ = 5/6:
  1.9048e-3 + 0.0149e-3 = 1.9196e-3 m (shear 0.77%). σ_xx = Mc/I = 48.0 MPa at
  x = 0.2 m, top face (outside the disturbance of the clamp). Reaction ΣRz = P.
  Measured: mean DZ of the end face; `stressxx` at the node nearest to
  (0.2; 0.05; 0.1).
- **Result**: hex20 n = 4: δ −0.81% (tol. 1%), σ_xx 0.00%. `LINE_QUAD` gives the same as
  hex20 on every mesh (same HEXA20 mesh). hex8 `3D`: δ −35.7 / −13.1 / −4.3 / −1.7 /
  −0.9% (n = 1…16). The reaction is exact on every mesh.
- **Interpretation**:
  - Quadratic: the differences between successive meshes (18.8e-6 and 4.7e-6 m) give
    p = 2.0 and the Richardson limit δ∞ = 1.9057e-3 m: +0.05% above Euler-Bernoulli and
    −0.72% below Timoshenko. That is a model error of beam theory: a fully held end
    face prevents warping and lateral contraction and stiffens about as much as the
    shear term adds. The singular edges of the clamp limit the order to 2. Mecway
    headless (internal solver and CCX, C3D20) gives δ = 1.904148e-3 (n = 4) and
    1.899446e-3 m (n = 2) on the same meshes, equal to the bridge to 7 digits.
    tol_f = 1%.
  - hex8 `3D` (fully integrated, without incompatible modes) is much too stiff with few
    elements through the height (KNOWN_BUGS 1); Mecway (incompatible hex8) gives −1.5 /
    −1.3 / −1.0% (n = 1, 2, 4) on the same meshes. The series converges with p ≈ 1.9 to
    the same limit (Richardson n = 4/8/16: 1.9067e-3 m). The nodal stress converges
    slowly and not monotonically (+0.8 / +1.3 / +0.9% at n = 4/8/16), as expected for an
    extrapolated nodal stress of a linear element (O(h)). tol_f: 2% (δ), 3% (σ).

### LS-03 Square plate, simply supported, uniform pressure

- **Purpose**: shells (DKT and `COQUE_3D`), `surfacepressure` on shell faces,
  `noderotation` and the von Mises fields of shells.
- **Model**: a = 1 m, t = 10 mm (a/t = 100), plane z = 0, n × n elements. Series quad4
  → DKT (n = 4, 8, 16, 32) and quad8 → `COQUE_3D` (n = 2, 4, 8, 16).
- **Boundary conditions and load**: all edge nodes DX = DY = DZ = 0 (three
  `displacement`s) and "hard" simple support: `noderotation` 0 about x on x = 0 and
  x = a, about y on y = 0 and y = a. Pressure 10 kPa on the top face.
- **Reference**: Navier series (Timoshenko & Woinowsky-Krieger, 1959, §30, table 8;
  m, n ≤ 401): w = αqa⁴/D with α = 0.0040624, D = Et³/12(1−ν²) → 2.1124e-3 m;
  M = βqa² with β = 0.047886 → σ = 6M/t² = 28.73 MPa. At the centre σ_x = σ_y and
  τ_xy = 0, so von Mises = |σ_x|; compared with `vonmisesu1`/`vonmisesb` (the bridge
  only sends von Mises of shells to Mecway).
- **Result**: DKT n = 32: w −0.003%, σ +0.06%. `COQUE_3D` n = 16: w +0.05%, σ +0.41%.
- **Interpretation**: DKT converges with p ≈ 2.1–2.3 (w) and 2.0 (σ) to 2.11241e-3 m and
  28.732 MPa (−0.0005% and +0.002%). `COQUE_3D`: σ with p ≈ 2.0 to 28.717 MPa (−0.05%),
  w to 2.11351e-3 m (+0.052%); that difference is the shear deflection of the Mindlin
  formulation, 2π²D/(κGta²) = +0.056%. Mecway (`COQUE_3D` mesh n = 16): 2.1146e-3 m
  (+0.05% relative to the bridge). tol_f: w 0.2%, σ 0.5% (DKT) and 1% (`COQUE_3D`).
  Two remarks on supports: (1) Mecway's `pinnedsupport` is "mean displacement zero" over
  the selection (the bridge translates it as `LIAISON_DDL`); an edge held node by node
  needs `displacement`. (2) With only DZ = 0 ("soft" support) `COQUE_3D` converges to
  +0.91% (w) and +1.06% (σ): the boundary layer of a Mindlin plate, an effect of order
  t/a. DKT (Kirchhoff) does not notice it. The hard support belongs to the Navier
  solution.

### LS-04 Thick-walled cylinder under internal pressure (Lamé)

- **Purpose**: `symmetry` (`LIAISON_OBLIQUE`), `frictionless` (`FACE_IMPO`) and pressure
  on a curved face.
- **Model**: a = 0.1 m, b = 0.2 m, quarter model (0–90°), axial thickness 0.01 m, one
  element in z; hex20, n radial × 2n tangential (n = 1, 2, 4, 8), mid-side nodes on the
  circle.
- **Boundary conditions and load**: `symmetry` on y = 0 and x = 0; `frictionless` on
  z = 0 and z = L (plane strain, ε_z = 0); pressure 100 MPa on the inner wall.
- **Reference** (Lamé; Timoshenko & Goodier, 1970): A = pa²/(b²−a²),
  B = pa²b²/(b²−a²); σ_θ(a) = A + B/a² = 166.67 MPa; σ_zz = 2νA = 20 MPa;
  u_r(a) = (1+ν)/E·[(1−2ν)Aa + B/a] = 9.0794e-5 m. Measured at the node (a, 0, 0):
  `displx`, `stressyy` (= σ_θ) and `stresszz`.
- **Result** n = 8: u_r −0.001%, σ_θ −0.18%, σ_zz +0.42%.
- **Interpretation**: u_r converges with p ≈ 3.8 to 9.07937e-5 m (exact), σ_zz with
  p ≈ 1.8 to 19.98 MPa. σ_θ on the inner wall (+0.10 / −0.62 / −0.46 / −0.18%) is still
  pre-asymptotic: the node lies on the symmetry plane and σ_θ ∝ 1/r² is extrapolated to
  the loaded edge. Further into the wall the error at the corner nodes is ≤ 0.15%, at
  the mid-side nodes 1–2% (n = 4), the usual picture of hex20 nodal stresses. tol_f:
  u_r 0.1%, σ_θ 0.5% (p = 1), σ_zz 1%.

### LS-05 NAFEMS LE1, elliptic membrane

- **Purpose**: a recognised benchmark with a stress concentration; shells as a membrane
  and solids; pressure on shell edges.
- **Model**: inner ellipse (x/2)² + y² = 1, outer ellipse (x/3.25)² + (y/2.75)² = 1,
  thickness 0.1 m, quarter model, point D = (2, 0). Mesh n × 2n (n = 2, 4, 8, 16),
  graded towards D in both directions (piecewise linear, so mid-side nodes are at the
  middle of the edge; a smooth grading puts them at the quarter point and gives a
  singular element at D). Series quad8 → `COQUE_3D` (DZ = 0 on all nodes) and hex20, one
  element thick (DZ = 0 at one node).
- **Boundary conditions and load**: `symmetry` on y = 0 and x = 0; pressure −10 MPa
  (tension) on the outer edge. On shell edges this becomes consistent nodal forces;
  check ΣR_x = −2.75 MN and ΣR_y = −3.25 MN (= p·t·2.75 and p·t·3.25).
- **Reference**: σ_yy(D) = 92.7 MPa, plane stress (NAFEMS, 1990, test LE1). Shell:
  `vonmisesm` (at D σ_xx = τ_xy = 0, so von Mises = σ_yy); solid: `stressyy`.
- **Result** n = 16: `COQUE_3D` 92.654 MPa (−0.05%), hex20 92.660 MPa (−0.04%).
- **Interpretation**: both series converge with p ≈ 3.8–4.1 to 92.66 MPa (Richardson);
  the remaining difference is within the rounding of the reference (92.65…92.75).
  tol_f = 0.5%. Mecway (`COQUE_3D` mesh n = 8): u_x(D) equal to 0.06%. Code-Aster 17.4
  itself has no LE1 test (it does have LE3 = ssls105a, §10).

### LS-06 Cantilever with a spring at the tip

- **Purpose**: Mecway spring (line2 with material *Spring*) along its own axis
  (`DISCRET` with `REPERE='LOCAL'`).
- **Model**: beam as LS-01 (10 line2, Ø 20 mm); a spring k = 1000 N/m from the tip to a
  fixed point 0.5 m away, (a) along Y, (b) at 45° in the XY plane.
- **Boundary conditions and load**: beam clamped, spring point `fixed`; P = 10 N in Y at
  the tip.
- **Reference**: beam and spring in parallel: (a) δ = P/(3EI/L³ + k), spring force kδ;
  (b) the tip moves (axially almost rigid) only in Y, the spring stretches δ/√2 and
  gives kδ/2 in Y: δ = P/(3EI/L³ + k/2).
- **Result**: (a) δ and spring force deviate 0.00% (tol. 0.1%); (b) δ 0.00% (tol. 0.2%).
- **Interpretation**: the spring acts along its own axis. Before the fix a spring always
  acted in global X, even when it lay along Y (KNOWN_BUGS 47 describes what has not yet
  been compared with Mecway).

### LS-07 Bonded contact between shells

- **Purpose**: Mecway's bonded contact (`bondedtie`) between plates with non-matching
  meshes → `LIAISON_MAIL` `TYPE_RACCORD='COQUE'`; does the seam carry a moment?
- **Model**: (a) cantilever plate strip 200 × 20 × 2 mm (DKT quad4) in two parts with
  their own nodes: A (x = 0..100 mm, 10 × 4) and B (x = 100..200 mm, 10 × 7), bonded
  along the seam (slave = edge of B, master = shell faces of A); (b) the same strip as
  one mesh 20 × 4. (c–e) T-joint: plate 100 × 60 mm, long edges clamped, with a rib
  60 × 40 mm (plane y = 30 mm) whose bottom edge is bonded onto the plate: (c) rib 13
  elements long against 20 in the plate, foot line on a mesh line of the plate; (d) foot
  line in the middle of the plate elements (15 across the width); (e) shared nodes.
  Example model (a): `TestFiles/Voorbeelden/Voorbeeld_T.liml`.
- **Boundary conditions and load**: (a, b) `fixed` on the edge x = 0, P = 1 N in −Z on
  the free edge; (c–e) 1 N in +Y on the top edge of the rib (the rib bends out of its
  plane; if the bond were a hinge, the model would be a mechanism).
- **Reference**: (a, b) Euler beam δ = PL³/(3EI), φ = PL²/(2EI) with E: with free side
  edges M_y = 0 and the bending stiffness per width is E t³/12; the clamping prevents
  the anticlastic curvature over a strip ~b (b/L = 0.1), which makes the plate slightly
  stiffer (tolerance 2 %). Also Mecway 34 (own solver) on model (b) (tolerance 0.5 %)
  and the rotation on both sides of the seam (equal, 0.5 %). (c, d) model (e) (same
  scheme) and Mecway 34 on (e).
- **Result**: (a) δ −1.07 % against Euler, +0.08 % against Mecway; φ −0.74 % and
  −0.00 %; rotation B/A across the seam 0.99992. (b) δ −1.03 %, Mecway +0.12 %.
  (c) +0.10 % below (e), +0.42 % against Mecway. (d) −5.2 % (tolerance 7 %). (e) +0.51 %
  against Mecway.
- **Interpretation**: the seam is rigid, also in bending: the bonded strip is within
  0.04 % of one continuous mesh. Before the fix in `bridge_mesh._coque_ddl`,
  `LIAISON_MAIL` also tied the rotation about the plate normal (only a fictitious
  stiffness in DKT) and Code-Aster stopped with `FACTOR_11`; now that rotation is left
  out when the master is normal to a global axis (otherwise KNOWN_BUGS 91). In (d)
  `LIAISON_MAIL` interpolates the plate rotation linearly across the kink under the
  rib: 12 mm elements −11 %, 4 mm −5 %, 1.3 mm −2 %; put the foot line on a mesh line.
  Mecway's own solver does not solve (a), (c) and (d): with a shell edge as slave it ties
  no rotations (mechanism, tip 3.7e6 m), so Mecway is only compared on the continuous
  meshes.

### LS-08 Node temperature (thermal stress per node)

- **Purpose**: Mecway's *Node temperature* (`temperature3`, a temperature per node, also
  the result of *Transfer temperatures from solution*) with a *Thermal stress* → nodal
  field `TEMP` in `AFFE_VARC`, like *Temperature* (`temperature2`).
- **Model**: α = 1.2e-5 1/K, E = 210 GPa, ν = 0.3, Tref = 293.15 K. (a) bar as TH-03b
  (1 × 0.1 × 0.1 m, 4 hex8, u_x = 0 at both ends, transversely free), Node temperature
  Tref + 100 K on all nodes. (b) free beam 100 × 10 × 10 mm (10 × 1 × 4 hex20) with
  T = Tref + 100 K · z/h on every node (linear through the thickness); u_x = 0 at x = 0,
  u_y = 0 at y = 0, u_z = 0 at the origin. (c) free bar 100 × 10 × 10 mm (4 hex8):
  `temperature2` Tref + 100 K on the nodes at x = 0 and Node temperature Tref + 200 K on
  those at x = L; the nodes in between get no temperature. (d) as (b) with hex8 and
  `elem_hex8` = `LINE_QUAD`.
- **Reference**: (a) σ_xx = −EαΔT, u_y = (1+ν)αΔT·b, reaction EαΔT·A. (b, d) linear
  temperature in a free body: stress-free, u_z = −αg(x² + y² − z²)/2 with g = ΔT/h
  (Timoshenko & Goodier §150): u_z(L, 0, 0) = −6.0e-4 m. (c) nodes without a temperature
  at Tref, element means +50 and +100 K: u_x(L) = α·150 K·L/4 = 4.5e-5 m. In addition
  Mecway 34 (own solver, headless) on (a)–(c).
- **Result**: all quantities exact (≤ 2e-10); max |σ_xx| in (b) and (d) 0.04 Pa.
  Mecway: (a) reaction 2.52e6 N, (b) −6.0000e-4 m, (c) 4.5000e-5 m, all three equal.

### Error estimator (FS)

Mecway S30 → `lin_static_3d` with `error_estimator` on (default) → `CALC_ERREUR`
`ERME` ([Error_estimator.md](Error_estimator.md)). Module `tests_foutschatter.py`, run
with `python run_verificatie.py FS`. The global estimate comes from the block
Code-Aster writes in the `.mess` (`verif_lib.error_summary`), the field `errorestimate`
from the result file. The order in a series is p = ln(η_coarse / η_fine) / ln 2 of
the absolute global estimate η between two successive meshes (h halved).

#### FS-01 Cantilever, hex8 (model of LS-02-h8)

- **Purpose**: does the estimate decrease with the expected order on refinement, does
  it follow the true error, and is the largest error where you expect it?
- **Model**: LS-02 (1 x 0.1 x 0.1 m, traction P = 10 kN on the end face, clamped end
  face fixed), hex8 `3D`, n = 1, 2, 4, 8, 16 elements over the height.
- **Reference**: (1) deflection: Timoshenko beam (Young & Budynas, 2002, table 8.1
  case 1a, plus shear), as LS-02. (2) True relative error in the energy norm: with a
  uniform traction the external work is P·w (w = mean deflection of the end face), so
  ‖u − u_h‖²_E = P (w_∞ − w_h) (Galerkin orthogonality) and the relative error is
  sqrt((w_∞ − w_h)/w_∞). w_∞ = 0.001906 m is the limit of the 3D model (Richardson on
  LS-02-h20: 0.0019057 m; on LS-02-h8 n = 4…16: 0.0019067 m). (3) Linear elements:
  energy error O(h), order 1 (Verfürth, 1996). (4) The error is largest at the
  singular edges of the clamped end.
- **Checks**: deflection (tolerance as LS-02); effectivity index = estimated / true
  relative error, expected O(1) and roughly constant (Ainsworth & Oden, 2000):
  2.0 ± 1.0; order of η 1.0 ± 0.2 (from n = 4); x of the node with the largest
  `errorestimate` at x = 0 (± one element).
- **Result**:

| n | nodes | global error (estimate) | η | order p | true error | effectivity | deflection vs w_∞ |
|---|---|---|---|---|---|---|---|
| 1 | 44 | 79.5% | 2.33e6 | – | 59.4% | 1.34 | −35.3% |
| 2 | 189 | 61.1% | 1.51e6 | (0.62) | 35.3% | 1.73 | −12.5% |
| 4 | 1025 | 37.9% | 8.22e5 | 0.88 | 18.9% | 2.01 | −3.6% |
| 8 | 6561 | 20.6% | 4.24e5 | 0.96 | 9.7% | 2.11 | −0.95% |
| 16 | 46529 | 10.7% | 2.17e5 | 0.96 | 4.8% | 2.22 | −0.23% |

  On every mesh the largest error is at the clamped end (x = 0).
- **Interpretation**: the global error decreases monotonically; η converges with order
  0.88 → 0.96, so towards 1 as expected for linear elements (n = 1 → 2 is not yet
  asymptotic). The relative error itself (η / sqrt(η² + ‖σ‖²)) has a lower order on the
  coarse meshes (0.69 between n = 2 and 4) because it saturates towards 100%; from
  n = 4 on 0.88 and 0.94. The effectivity index is O(1) and rises only slowly
  (1.3 → 2.2): the estimator is a reliable, slightly pessimistic measure of the energy
  error. The deflection error is much smaller than the energy error (roughly its
  square).

#### FS-02 Thick-walled cylinder, hex20 (model of LS-04)

- **Purpose**: order with quadratic elements and a smooth solution; location of the
  largest error.
- **Model**: LS-04 (a = 0.1 m, b = 0.2 m, p = 100 MPa, quarter cylinder, symmetry on
  the side faces, frictionless on the ends, outer wall free), hex20, n = 1, 2, 4, 8
  elements across the wall (2n around).

  solution: energy error O(h²), order 2; the largest stress gradient at the inner

- **Checks**: u_r inner wall (as LS-04); order of η 2.0 ± 0.3; radius of the node with
  the largest `errorestimate` = a (± one element).
- **Result**: global error 12.5 / 3.44 / 0.894 / 0.239%; order 1.87 / 1.95 / 1.91; the
  largest error at the inner wall on every mesh.
- **Interpretation**: order 2 as expected. The free outer wall gets the bridge's
  pressure ~0 (two to sixteen free faces); the symmetry and frictionless faces have
  no boundary term.

#### FS-03 Code-Aster test case sslv153a through the bridge

- **Purpose**: the same estimate as Code-Aster's own test case, through the whole
  chain (`.liml` → bridge → Code-Aster), with a mixed mesh.

### Adaptive refinement (AD)

Mecway S30 → `lin_static_3d` with `adapt_refine` on → after each run
`bridge_adapt.after_run` chooses the elements (by default with Dörfler's criterion,
Dörfler, 1996) and `bridge_adapt.refine_in_mecway`
refines them in Mecway ([Error_estimator.md](Error_estimator.md) §6). Module
`tests_adaptief.py`, run with `python run_verificatie.py AD`. The loop of the main
script runs offline with the same functions: the bridge and Code-Aster as in every
case, the refinement in **headless Mecway** (`mecway.exe <model> script <script.py>`,
with `bridge_adapt.refine_in_mecway(mw, ...)`). The intermediate models are
`TestFiles/Verificatie/modellen/AD-02-L0.liml` … `AD-02-L5.liml` (open them in Mecway);
if headless Mecway is not available (`mecway.exe` not found or the refinement fails),
the loop falls back to those stored models; the check "lus met Mecway gedraaid" (loop
run with Mecway: the fraction of refinement steps that Mecway actually did, reference
1, tolerance 0) is then NOK, so AD-02 never passes silently on old models.

- **Model**: quarter plate with a circular hole (r = 10 mm) in tension 100 MPa, width W =
  100 mm (d/W = 0.2), length 300 mm, hex20; a slab of 10 mm with symmetry on both z
  faces (plane strain). Plane strain and plane stress give the same Kt (the stresses of
  a plane problem with boundary loads do not depend on ν); checked with the same plate
  1 mm thick in plane stress: n = 32 −0.08%.
- **Reference**: Kt_n = σ_xx(0, r) / σ_nom with σ_nom = σ W/(W − d); Peterson (Pilkey &
  Pilkey, 2008, chart 4.1): 2 + 0.284(1 − d/W) − 0.600(1 − d/W)² + 1.32(1 − d/W)³ =
  2.519; as a check Heywood (1952) 2 + (1 − d/W)³ = 2.512 and Roark (Young & Budynas, 2002, table 17.1, case 2a)
  2.508. Done criterion S7: Kt within 2% after the loop, with fewer elements than
  uniform refinement.

## 5. Nonlinear static (NL)

Mecway L30 → bridge `nonlin_static_3d` → `STAT_NON_LINE`. Module
`tests_niet_lineair.py`, run with `python run_verificatie.py NL`. Default settings:
`deformation` = `GROT_GDEP`, converted by the bridge per element to `GDEF_LOG` (plastic
solids), `GREEN_LAGRANGE` (elastic solids) and `GROT_GDEP` (`COQUE_3D`);
`convergence_resi_rela` = 1e-5 (the bridge default; the Code-Aster default 1e-6 stalls
in NL-01, see there); the solver steps are Mecway's *Time step size* (0.1 s, as in the
samples) plus the kinks of the load tables (NL-20).

### NL-01 Tensile bar, bilinear isotropic hardening, unloading

- **Purpose**: bilinear plasticity (`BilinearIsotropic`), large strains (`GDEF_LOG`) and
  elastic unloading.
- **Model**: bar 100 × 10 × 10 mm, 2 × 1 × 1 hex20; E = 210 GPa, ν = 0.3,
  σy = 355 MPa, *tangent modulus* H = 10 GPa.
- **Boundary conditions and load**: symmetry planes x = 0, y = 0, z = 0 (lateral
  contraction free); prescribed elongation at x = L: 0 → 0.10 mm (t = 1 s, elastic) →
  1.00 mm (t = 2 s, plastic) → 0.85 mm (t = 3 s, unloading).
- **Reference**: homogeneous uniaxial state, exactly computable. With `GDEF_LOG`
  (additive logarithmic strain; the dual stress is the Kirchhoff stress τ in uniaxial
  tension without rotation): τ = σy + H·p, p = ln(1+e) − τ/E, elastic unloading;
  F = A0·τ/(1+e), σ = τ/J with J = exp((1−2ν)τ/E). Tolerance 0.2% (every element is
  exact; what remains is the Newton tolerance and J − 1 < 0.1%).
- **Result**: F, σ_xx and p at t = 1, 1.5, 2 and 3 s (after unloading: F = 12 071 N)
  deviate 0.00%, with the default settings. NL-01b (same model with the Code-Aster
  default `convergence_resi_rela` = 1e-6, `convergence_criterion` = `RELA_OF_MAXI` and
  `convergence_resi_maxi` = 0.05 N) also runs to t = 3 s, 0.00% off.
- **Interpretation**:
  1. *Tangent modulus*. Mecway's *tangent modulus* is the plastic modulus H (stress
     against plastic strain), not a slope in total strain. Decisive (Mecway/CCX
     headless, *tangent modulus* 100 GPa, 1% strain): CCX 915.8 MPa, read as H
     914.5 MPa, read as a slope in total strain 1181 MPa. The bridge now gives
     Code-Aster `D_SIGM_EPSI` = E·H/(E+H) (slope in total strain; EDF R&D, U4.43.01);
     before that fix the peak force was 0.87% too high.
  2. *Unloading*. With the Code-Aster default 1e-6 and only `RESI_GLOB_RELA`, Newton
     stalls at RESI_GLOB_RELA 1.5–2.3e-6 (residual force ~1e-2 N at 12 kN); the step is
     subdivided 6 times and the run stops at t = 2.92 s (`MECANONLINE9_7`). Up to that
     moment every step is exact, so the norm is just too strict for this state. That is
     why the bridge default is 1e-5 (NL-01). With 1e-6 it continues with `RELA_OF_MAXI`
     and an absolute limit above the stalled residual (NL-01b, 0.05 N; not with
     1e-3 N) or with `DEFORMATION` = `PETIT`.
  3. *Strain measure*. With `PETIT` the bridge gives exactly the small-strain formula
     F = A0·(σy + H·p); the difference from the logarithmic strain is 1.1% at 1% strain.

### NL-20 Mecway's step size with kinks of the load table in between

- **Goal**: nonlinear static computes with Mecway's *Time step size*
  (`<timesteps stepsize>`) and still follows the load path
  exactly.
- **Model**: NL-01 with `<timesteps timeperiod="3 s" stepsize="0.4 s">`; the kinks of the
  imposed elongation (t = 1 and 2 s) fall between two steps.
- **Reference**: output times 0.4; 0.8; 1.0; 1.2; 1.6; 2.0; 2.4; 2.8; 3.0 s (Mecway's
  steps plus the kinks); F, σ_xx and p as NL-01.
- **Result**: the output times match exactly; F, σ_xx and p at t = 1, 2 and 3 s 0.00%
  off (the same values as NL-01 with 30 steps).
- **Interpretation**: the kinks as an extra solver step keep the load linear per step, so
  radial return stays exact. Mecway's own output times were not checked headless
  (Mecway solve was not available when this case was added).

### NL-02 Cantilever, large deflection (elastica)

- **Purpose**: large displacements and rotations with solids (`GREEN_LAGRANGE`) and
  `COQUE_3D` (`GROT_GDEP`).
- **Model**: L = 1 m; (a) solid 10 × 10 mm, 20 × 1 × 2 hex20; (b) strip 50 mm wide,
  10 mm thick, 20 × 1 quad8 with `elem_shell` = `COQUE_3D`. E = 210 GPa, ν = 0 (the
  elastica does not depend on ν; this avoids lateral contraction at the clamp).
- **Boundary conditions and load**: clamped at x = 0; tip force in −z with a fixed
  direction (`force` on the nodes of the end face, `FORCE_NODALE`), time table
  PL²/EI = 1, 2, 3 at t = 1, 2, 3 s.
- **Reference**: inextensible Euler elastica θ'' = −α cos θ, solved numerically (RK4 and
  shooting) in the test module; equal to Bisshopp & Drucker (1945) and Mattiasson
  (1981): α = 1: v/L 0.30172, u/L 0.05643; α = 2: 0.49346 / 0.16064; α = 3: 0.60325 /
  0.25442. Measured at the node on the axis at the tip. Tolerance 1% (discretisation;
  shear ~1e-4 and axial strain ~1e-5 are negligible).
- **Result**: (a) hex20 −0.12 … −0.57% (slightly stiff, growing with the load);
  (b) `COQUE_3D` +0.01% at all levels.
- **Interpretation**: large displacements work for solids and `COQUE_3D`, and the force
  keeps its direction. Beam elements and DKT stay geometrically linear in the bridge
  (KNOWN_BUGS 11) and are not tested.

### NL-03 Contact

**NL-03a/b: two cantilevers with their tips on each other.**

- **Purpose**: line contact between hex20 solids, Lagrange (a) and penalty (b).
- **Model**: two beams 100 × 10 × 5 mm (b × h), both clamped at x = 0, hex20 20 × 1 × 1
  (lower beam 22 elements, 10 mm overhang). The top face of the lower beam touches the
  upper beam only at x = L (no gap) and drops 0.5 mm towards the clamp: the contact is a
  line at x = L. Frictionless; slave = underside of the upper beam (last 20 mm), master
  = top of the lower beam. E = 210 GPa, ν = 0 (with ν = 0.3 the 3D model gave 1.35% less
  deflection than beam theory because of plate action at the clamp, with ν = 0 0.01%).
- **Boundary conditions and load**: P = 10 N in −z on the end face of the upper beam;
  (a) `contact_algo` = STANDARD, (b) PENALISATION with kn = 1e13 Pa/m.
- **Reference**: C = L³/3EI + L/(κGA) (Young & Budynas, 2002, table 8.1, case 1a, plus
  shear); equal stiffness, so contact force R = P/2 and tip of the upper beam
  (P − R)·C = 7.6305e-5 m. The mean (w_upper + w_lower)/2 = P·C/2 holds for any contact
  law. Tolerance 0.5%.
- **Result**: (a) no usable result: the edge penetrates between the integration points
  (R ≈ 0) and at t ≈ 0.03 s Code-Aster stops with `MECANONLINE9_4` (matrix not
  invertible); status BEKEND (KNOWN_BUGS 43). (b) tip −0.01% (mean) / +0.07% (upper),
  R = 4.996 N (−0.07%).
- **Interpretation**: Lagrange contact fails for this line contact on hex20 (QUAD8
  faces). Also tried earlier, without success: `AUTO` (zero pivot on `LAGS_C` of a
  corner node in the first step, also with master and slave swapped), `GAUSS` (same
  picture as `NCOTES`) and `NCOTES` with swapped roles (runs, but R = 4.74 N and upper
  tip +7%). Penalty is exact: R = P/(2 + k_b/K_c) with k_b = 1/C gives K_c ≈ 5e7 N/m, so
  the effect of kn = 1e13 Pa/m is < 0.1%. A softer kn lets the beams penetrate and
  shifts load to the upper beam (the mean stays the same).

**NL-03c–f: contact patch test.**

- **Purpose**: contact between non-matching quadratic meshes, Lagrange and penalty, and
  the translation of Mecway's *normal stiffness*.
- **Model**: two blocks 20 × 20 × 10 mm on top of each other, lower block 2 × 2 × 1
  hex20, upper block 3 × 3 × 1 hex20; E = 210 GPa, ν = 0.3.
- **Boundary conditions and load**: symmetry planes x = 0 and y = 0 (both blocks),
  bottom z = 0 held in z; 4000 N uniformly on the top (p = 10 MPa). (c, e) STANDARD,
  (d, f) PENALISATION with kn = 1e13 Pa/m; (e, f) with the integration set explicitly as
  `#ASTER-ZONE INTEGRATION='NCOTES'`.
- **Reference**: uniaxial compression, contact pressure p everywhere: compression
  p·H/E = 4.762e-7 m per block; with penalty an extra p/kn = 1.0e-6 m (Mecway: contact
  pressure = *normal stiffness* × penetration). Tolerance 0.5% (the state can be
  represented exactly).
- **Result**: all displacements and the penetration deviate ≤ 0.01%, in c–f.
- **Interpretation**: `COEF_PENA_CONT` = Mecway's *normal stiffness* is translated
  correctly (NL-03d/f; Mecway/CCX headless on the same model: −1.95245e-6 m against the
  reference −1.95238e-6 m). With the former default integration (`AUTO`, for these faces
  equal to `SIMPSON`) Code-Aster did not pass the patch test (STANDARD up to +2.8% /
  −1.5%, PENALISATION +4.6% and penetration −2.1%); the bridge therefore now sets
  `NCOTES` for a quadratic slave face. With matching meshes `AUTO` is exact as well.
  `NCOTES` has not been tested separately on tet10 or curved faces (the Mecway samples
  PipeClip and AssemblyWithContact do run with it, see `bridge_to_aster.py`).

## 6. Dynamics (DY)

Mecway D31 with `<timesteps>` (output interval `timepointsincrement`). Implicit:
`dyna_impl_3d` (`DYNA_NON_LINE`, HHT or NEWMARK, `substeps_per_output` = 1, so solver
step = output interval). Explicit: `dyna_expl_3d` (`DIFF_CENT`, lumped mass, step
≤ 0.5 × the estimated critical time step, evenly distributed over the output interval).
Module `tests_dynamisch.py`, run with `python run_verificatie.py DY` (about 1 minute).

**Tolerances.** The expected deviation comes from the same time scheme, computed in
Python independently of the bridge:
- `scheme_period_ratio`: period elongation and numerical damping from the eigenvalues
  of the amplification matrix (Hughes, 2000, ch. 9; HHT: Hilber et al., 1977, with
  γ = 1/2 − α and β = (1 − α)²/4);
- `sdof_response` / `modal_step_response`: the scheme on a single-degree-of-freedom
  system or on exact eigenmodes;
- `bar_chain`: the bar as a 1D chain (consistent mass + HHT, or lumped mass + central
  differences).

Tolerance = 1.5 × the expected deviation + a margin (0.1% for period and single degree
of freedom, 0.2% for the rest), rounded to 2 digits. In addition the check "verloop
t.o.v. schema/keten" (response against scheme/chain): max |u_FEM − u_Python| / max |u|
over all output times; limit 1e-5 where the Python model is exact (DY-01, DY-03; output
in single precision, Newton `RESI_GLOB_RELA` 1e-5) and 0.2% for DY-02 (mesh error of the higher modes).

**Code-Aster behaviour the comparison needed** (measured with 17.4; not found in the
U documentation):
- The initial acceleration follows from equilibrium at t = 0: a0 = M⁻¹F(0), also
  implicit.
- HHT, first step: the term −αF₀ uses F₀ = 0, even for a load that is already on at
  t = 0. With F₀ = F, DY-01a deviates 1.5% of the amplitude, with F₀ = 0 4e-8. A step
  load therefore gets a slightly too small impulse in the first HHT step (DY-01a: peak
  −0.44% at α = −0.1 and Δt = T/20; vanishes as Δt → 0). Newmark does not have this.

### DY-01 Mass-spring system, step load

- **Purpose**: spring (`DIS_T K_T_D_L`), nodal mass (`mass2` → `POI1 M_T_D_N`), step load
  and the scheme settings.
- **Model**: line2 with Mecway *Spring* k = 1000 N/m from a fixed node to a node with
  m = kT²/4π² = 25.33 kg (T = 1 s); the mass node is free only in X.
- **Boundary conditions and load**: F = 10 N from t = 0, 5 periods. DY-01a HHT α = −0.1
  (Δt = T/20); DY-01b/c/d Newmark (trapezoidal rule) with Δt = T/10, T/20, T/40.
- **Reference**: u = F/k·(1 − cos ωt): period 2π√(m/k), maximum 2F/k (Clough & Penzien,
  1993). Period measured as the least-squares line through the crossings of F/k, peak
  with a parabola through the largest sample.
- **Result**: period +1.02% (HHT) and +3.21 / +0.81 / +0.21% (Newmark), each equal to
  the prediction of the scheme; convergence order 1.98 and 1.99 (theory 2: period error
  (ωΔt)²/12). Peak −0.44% (HHT), 0.00…−0.02% (Newmark). Response against the recursion
  of the scheme 4.5e-8.
- **Interpretation**: spring, mass, load, output times and scheme arrive in Code-Aster
  exactly; the deviations are the known period error of the scheme.

### DY-02 Cantilever, first natural period

- **Purpose**: consistent mass and stiffness of beam elements in time.
- **Model**: cantilever L = 1 m, round Ø 20 mm, steel (ρ = 7850 kg/m³), 20 line2
  (`POU_D_E`). HHT α = −0.1, Δt = T1/40, 6 periods.
- **Boundary conditions and load**: clamped; step load 10 N in Z at the tip (free
  vibration about the static position).
- **Reference**: f1 = (1.875²/2π)·√(EI/(mL⁴)) = 14.47 Hz, T1 = 0.06910 s (Blevins, 1979,
  table 8-1). Tip displacement as modal superposition Σ c_i(1 − cos ω_i t) with
  c_i = 4FL³/(EIλ_i⁴) (30 modes, Σ c_i = FL³/3EI); maximum 1.9658 × static.
- **Result**: period +0.27% (expected with HHT +0.268%), maximum −0.30% (expected
  −0.297%), response against 30 modes with HHT 2.8e-6.
- **Interpretation**: beam stiffness and mass are correct; the deviation is the HHT
  period error. Rotary inertia and mesh error are negligible here.

### DY-03 Longitudinal wave in a bar

- **Purpose**: density, lumped mass, critical time step and step division,
  `FORCE_FACE` and a prescribed velocity in explicit dynamics.
- **Model**: bar L = 1 m, 10 × 10 mm, 100 × 1 × 1 hex8 (h = 10 mm), steel with ν = 0
  (the motion is then exactly 1D, c = √(E/ρ) = 5172 m/s). `deformation` = `PETIT`: with
  the default (`GREEN_LAGRANGE` for solids) the response deviates 1.4e-4…6.9e-4 from the
  linear chain (strain ~5e-5), which is physical and not an error.
- **Boundary conditions and load**: x = 0 fixed. DY-03a explicit, step load
  F = 1000 N at x = L; DY-03b explicit, prescribed velocity v = 0.25 m/s at x = L
  (output every 5 µs, end 600 µs = 3.1 L/c, 6 solver steps per output interval); DY-03c
  implicit HHT, step load, Δt = 10 µs (T/77), end 2.4 ms.
- **Reference** (Graff, 1975): behind the front σ = F/A resp. ρcv; particle velocity
  F/(ρcA); arrival at the clamp after L/c; reflection at the fixed end doubles the
  reaction; tip displacement vt up to 2L/c, maximum 2FL/EA; period of the fixed-free bar
  4L/c.
- **Result**: DY-03a: tip velocity +0.21%, stress +0.09%, arrival +0.90% (the front lags
  ~1 element because of dispersion), reaction −0.06%, maximum −0.58%. DY-03b: stress
  +0.08%, reaction −0.04%, prescribed u and v exact. DY-03c: period +0.23%, tip velocity
  +0.76%, maximum −2.67% (HHT damps the high harmonics that form the kink of the
  triangular wave). All three follow the 1D chain to 4e-8.
- **Interpretation**: the explicit and implicit translation is exact; converting a
  prescribed velocity into an acceleration (`FORMULATION='ACCELERATION'`) works.
  Implicit gives a smoother wave front on the same mesh (peak −2.7% against −0.6%
  explicit) with ~12× fewer steps.

### TH-01 Steady-state conduction

  - TH-01d: q = 1e6 W/m³, x = 0 insulated, convection h = 500 W/m²K (Bi = 0.5);

    400 K.
- **Reference** (Incropera et al., 2007, §3.1, 3.5 and 3.6.2): T_max − T0 = qL²/8k =

  T(L) = 366.67 K, q = 16 667 W/m² (c); Ts = T∞ + qL/h = 400 K, T(0) − Ts = qL²/2k =

  hex8 block, the solution with linear 1D elements; Galerkin gives exact nodal values
  for −kT'' = q, also with a convection boundary, and hex20 is exact for a quadratic T.
  The nodal average of the flux for two equal elements is the central difference, exact
  for quadratic T. The tolerance is therefore rounding only. TH-01e: mL = 1.58 and 10
  quad8 give a discretisation error ~(mh)⁴ < 1e-4; this also checks the thickness factor
  (`PLAN`, f = t) and the convection on the shell face (`SOUR_NL`, `THER_NON_LINE`).

### TH-02 Transient: semi-infinite body

- **Purpose**: `THER_LINEAIRE` transient: θ scheme (setting `theta`), time step, ρ·cp,
  initial and boundary temperature.
- **Model**: bar 0.1 m, 100 hex8 elements (h = 1 mm, cross-section 2 × 2 mm, side faces
  insulated), λ = 10 W/mK, ρ = 1000 kg/m³, cp = 1000 J/kgK (α = 1e-5 m²/s); initial
  temperature Ti = 300 K, boundary temperature Ts = 400 K at x = 0 from t = 0 (the bar
  is long enough to be semi-infinite). TH-02a/b/c: θ = 0.57 / 0.5 / 1.0 at Δt = 0.1 s;
  TH-02d–f: Δt = 0.4 / 0.2 / 0.05 s at θ = 0.5 and 1.0; TH-02g/h/i: coarse step
  Δt = 1 s (Δt·α/h² = 10), θ = 0.5 / 0.57 / 1.0.
- **Reference**: T − Ti = (Ts − Ti)·erfc(x/2√(αt)) (Carslaw & Jaeger, 1959, ch. 2;
  Incropera et al., 2007, §5.7), at t = 10 and 40 s (a–f) or 4 s (g–i). In addition a
  replica: `_fe1d_theta` computes the same discrete problem in 1D (linear elements,
  consistent mass, θ method, T(0) = Ts from the first step).
- **Result**: largest deviation from erfc 0.12 K (a–c, tolerance 0.5 K), 0.51 K (d–f,
  Δt = 0.4 s, θ = 1; tolerance 1 K) and 3.1 K (g–i, tolerance 5 K). Difference from the
  replica ≤ 1.3e-5 K in all 15 cases (tolerance 1e-4 K).
- **Interpretation**: the replica proves that θ, Δt, ρ·cp, λ and the initial and
  boundary temperature are in the `.comm` exactly as intended; the tolerance 1e-4 K
  follows from the single precision in which the bridge writes transient results (ulp
  at 380 K = 3e-5 K). The deviation from erfc is scheme error: the jump of the boundary
  temperature at t = 0 is smeared over the first step (order Δt, ≤ 0.25 K at
  Δt = 0.1 s); the spatial error at h = 1 mm is < 0.02 K. The tolerances 0.5 / 1 / 5 K
  were estimated with the same 1D scheme.

**Effect of θ** (setting `theta`):

| θ | T − Ti at 8 mm, 10 s (Δt 0.1 s; ref. 57.161 K) | T − Ti at 1 mm, 4 s (Δt 1 s; ref. 91.10 K) |
|---|---|---|
| 0.5 (Crank-Nicolson, = Mecway) | 57.070 | 93.89 (overshoots +2.8 K) |
| 0.57 (default of bridge and Code-Aster) | 57.065 | 91.71 |
| 1.0 (implicit Euler) | 57.037 | 90.16 |

- With a small step (Δt·α/h² = 1) θ makes little difference: the error is dominated by
  the jump at t = 0 and converges with order 1 in Δt for all θ (measured p = 0.97–1.13,
  table "Mesh-convergentie" in `resultaten.md`), also for Crank-Nicolson, which is
  second order for smooth problems.
- With a coarse step (Δt·α/h² = 10) Crank-Nicolson overshoots near the surface (no
  discrete maximum principle); θ = 0.57 damps that, θ = 1 is monotonic but slower. That
  is scheme behaviour, not a bridge error (the replica gives the same values).
- Mecway computes Crank-Nicolson with the load at the end of the step; for a constant
  boundary temperature that equals θ = 0.5 ([Thermal.md](Thermal.md) §5). To follow
  Mecway exactly, choose `theta` = 0.5; the default 0.57 is slightly damped.

  - WE-12 proves the stress-free birth: without birth the bar would be stress-free after
    cooling back; with birth at T0 + 100 K, B shrinks α·ΔT relative to its birth
    temperature and σ = E·α·ΔT = 252 MPa follows. The residual stress in A is 30 kPa
    lower than in B: at birth A had the stress with which it compressed the quiet B
    (E × 10⁻⁴) (−60 kPa); B starts at zero.
  - Found and fixed in this step: (1) Code-Aster 17.4 computes two `AFFE_CHAR_THER_F`
    loads with `SOURCE` in one analysis both with the function of the first (with two
    sources WE-11 received 2 × the energy of source 1 and source 2 never acted; also
    with constant `FORMULE`s): the weld sources are now in one load (KNOWN_BUGS 70, the
    Mecway formula sources not yet); (2) with the consistent heat capacity a quiet node
    followed the temperature rate of its hot neighbours through the mass coupling
    (WE-13: +138 K before birth, with a dip below T0 while they heated): the filler now
    uses `3D_DIAG`; (3) the source was sometimes off at the end time by rounding (v·
    (t_end − t0) just above L): now with a margin of 10⁻⁹.

## 9. Assumptions and not covered

**Assumptions of the verification**
- The reference is an analytical solution of the idealised problem (linear elasticity,
  Euler or Timoshenko beam, Kirchhoff plate, 1D wave, semi-infinite body). Where the FE
  model describes something slightly different (3D clamp, Mindlin shell), this is named
  as a model error and included in the tolerance.
- Quantities are read at nodes (`displ*`, `stress*` = `SIGM_NOEU`, von Mises of shells,
  `temperature`, `heatflux*`), i.e. as the user sees them in Mecway. Nodal stresses are
  extrapolated and averaged and converge more slowly than displacements.
- Transient results are stored in single precision in the results file (see TH-02);
  steady-state and mechanical results in double precision.
- Mecway comparisons were solved headless with Mecway 33 (`mecway.exe model.liml solve`
  with `<solutionfile>`); Mecway's internal solver does not compute plasticity, CCX was
  used for that.

**Not covered by these tests** (partly compared elsewhere; checked against §4–§8):
- radiation (`RAYONNEMENT`; Code-Aster test tpna01b in §10 and the comparison with
  Mecway in [Thermal.md](Thermal.md) §5), `heatflow` on nodes, time tables for thermal
  loads other than an imposed temperature (that one is covered: WE-07 .. WE-10, MT) and
  thermal shells outside Z = constant (idem);
- kinematic hardening and Ramberg-Osgood (bilinear isotropic is covered: NL-01, WE-08,
  VM-11a; a hardening curve: WE-12c; see the variants in [Failure.md](Failure.md) §5),
  element failure ([Failure.md](Failure.md) §5);
- friction (NL-03 is frictionless), bonded contact except shell on shell (LS-07),
  contact in dynamics (implicit and
  explicit);
- beams and DKT at large displacements (KNOWN_BUGS 11; NL-02 only solids and
  `COQUE_3D`);
- gap and tension-only elements, dampers in transient dynamics (DY, MD; dampers are
  covered in harmonic response and complex modes: HR-01d, MC, VH-04c).

Covered and therefore no longer in this list: a temperature field as a load in a
mechanical analysis (TH-03; from a thermal analysis: WE-07 .. WE-10, MT), centrifugal
load (MP-04, CY), dampers (HR-01d, MC, VH-04c) and a hardening curve (WE-12c).
